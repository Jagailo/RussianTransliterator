# Security Policy

## Supported Versions

Only the latest released version receives security fixes.

| Version | Supported          |
|---------|--------------------|
| 1.1.x   | :white_check_mark: |
| < 1.1   | :x:                |

## Reporting a Vulnerability

Please **do not** report security vulnerabilities through public issues.

Report them privately via [GitHub Security Advisories](https://github.com/Jagailo/RussianTransliterator/security/advisories/new)
(the **Report a vulnerability** button on the **Security** tab).

Please include:
- the affected version;
- a description of the issue and its impact;
- steps or input to reproduce it.

You can expect an initial response within 7 days. If the vulnerability is confirmed, a fixed version will be published on NuGet
and the advisory will be disclosed after the release. If the report is declined, you will receive an explanation.
